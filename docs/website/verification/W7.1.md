## INTEGRATE

Pass criteria: no runtime dependency; private package; `track()` synchronous; no throw into the host; queue bounded and oldest dropped; retries on network, 429 and 5xx only; `Retry-After` honoured; five attempts; 60 second pause after five failed batches; shutdown bounded; key absent from string forms; user agent control characters stripped; sensitive attributes and request bodies never sent.

All passed. `JSON.stringify`, `String()`, `util.inspect()` and template interpolation were each checked for the secret.

## ACT

The first suite run hung because shutdown did not stop a retry that was sleeping. The SDK now marks the instance aborted after the shutdown deadline, and retry timing is configurable for tests. The production defaults remain one second base and five attempts.

W10 is VERIFIED on Node 24.

## Limitations

- Only Node 24 was tested. `engines` therefore declares `>=24`, not a wider range.
- ESM only. No CommonJS build and no dual package test.
- The package is not published. Installing from a path or copying `src/index.js` is documented.
- No browser bundle and no automatic request capture by design.
