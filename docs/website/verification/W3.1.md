## PLAN

Build a labelled corpus with a benign set that must produce zero detections and an attack set built from the attack types the rules support. Report true positives, false positives, false negatives, precision, recall and F1, and state the dataset size.

## CALL

```powershell
cd backend
node --test tests/website-detection.test.mjs
```

## PAUSE

```text
[detection-quality] benign=93 attack=77 tp=4 fp=0 fn=0 precision=1.000 recall=1.000 f1=1.000
  rules=w-req-003,w-auth-003,w-auth-001,w-acc-001
✔ benign traffic produces no detection
✔ the attack corpus is detected with measured precision and recall
ℹ tests 2
ℹ pass 2
ℹ fail 0
```

Benign cases: three failures then a success, fifty different users from one office address, fourteen suspicious paths in five minutes, twenty application errors, five heartbeats. None produced a detection or an incident.

Attack cases: sixty failures from one address across twenty five accounts, a success for one of those accounts, twelve access denials for that account, four SQL injection attempts. The four expected rules fired, one incident was created, severity became critical and priority P2.

## INTEGRATE

The numbers are exactly as stated and are produced by the test, not typed into the document by hand. Precision and recall are 1.000 on this corpus because the corpus was built to exercise the documented thresholds. This is a regression measurement, not a field accuracy claim.

## ACT

No rule changes were needed. The first run exposed that the benign wait helper waited for a detection count of 1000 and spent eight seconds timing out; the test now reads the list once after a short wait.

## RECORD

W5 is VERIFIED for the corpus. Detection tuning against real traffic is residual work.

## Limitations

- 170 events across two sites is small.
- The attack categories are exactly the ones the rules implement; unknown attack classes are not measured.
- Thresholds remain starting values from the prompt.
- The corpus is not shipped as customer data and uses documentation address ranges and `.test` hostnames.
