## Export and deletion

Covered by `website-api` tests:

- Export requires an admin, is scoped to the organization and contains no key material.
- Deletion requires the exact hostname and a recent password confirmation.
- Deletion removes events and idempotency markers and records counts in `website_deletion_requests`.
- A wrong confirmation returns `400 confirmation_mismatch`.
- The audit log records `website.data_deleted`.
